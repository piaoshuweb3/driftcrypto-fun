# driftcrypto.fun — Feature Introduction & Deployment Guide

## Project Overview

**driftcrypto.fun** is an AI-powered cryptocurrency insights platform that delivers real-time market data, AI-driven news aggregation, intelligent market analysis, and conversational AI assistance. The platform supports bilingual (English/Chinese) real-time switching.

---

## Feature Introduction

### 1. Real-Time Market Dashboard

- **Hero Stats**: Total Market Cap, 24h Volume, BTC Dominance — fetched from CoinGecko API with 60s auto-refresh
- **Market Overview Table**: Top 100 coins ranked by market cap with search, filtering (All/Top 10/Top 50/Gainers/Losers), and pagination
- **Trending Strip**: Horizontal scrollable badges showing top 7 trending coins with 24h change indicators

### 2. AI News Aggregation

- **Multi-source Search**: Parallel web search across "cryptocurrency news", "AI blockchain news", "crypto market analysis" queries
- **Sentiment Analysis**: Automatic bullish/bearish/neutral classification with keyword matching (supports English + Chinese keywords)
- **Filter Tabs**: All / Bullish / Bearish / Neutral with animated card transitions
- **Bilingual Content**: Mock data available in both EN and ZH; real-time language sync when switching locales
- **Deduplication**: URL-based deduplication across search results
- **Database Caching**: Prisma SQLite upsert for persistent storage

### 3. Fear & Greed Index

- **Semi-circular Gauge**: SVG gauge with gradient arc, animated needle, and glow effects
- **5-level Classification**: Extreme Fear / Fear / Neutral / Greed / Extreme Greed
- **Historical Data**: 30-day cached with auto-refresh

### 4. AI Market Digest ("Piaoshu Commentary")

- **AI-Generated Summaries**: Daily digest generated by LLM with markdown-like rendering (headings, bold text)
- **Source Attribution**: Badge showing "AI Generated" with timestamp
- **Auto-refresh**: 1-hour cache with background refetch

### 5. AI Chat Assistant

- **Conversational Interface**: Multi-turn chat with message history
- **Bilingual Responses**: System prompt adapts to current locale (EN/ZH)
- **Typing Indicator**: Animated dots while AI processes
- **Error Recovery**: Retry mechanism for failed requests
- **Disclaimer**: AI-generated content notice displayed below chat

### 6. Bilingual System (i18n)

- **100+ Translation Keys**: Complete EN/ZH coverage for all UI elements
- **Real-Time Sync**: All components update instantly on language change
- **Browser Detection**: Auto-detects Chinese browser and switches to ZH
- **localStorage Persistence**: Language preference persisted across sessions
- **Cross-Tab Sync**: Language changes propagate across browser tabs via storage events
- **Hydration-Safe**: Uses `useSyncExternalStore` with server snapshot to prevent React hydration mismatches

### 7. Investment Disclaimer

- **Prominent Footer Section**: Bordered warning box with ShieldAlert icon
- **Bilingual**: Full disclaimer text in both EN and ZH
- **Always Visible**: Placed at the top of the footer for maximum visibility

### 8. Authentication System

- **Multi-provider**: Google OAuth, X (Twitter) OAuth, Wallet Address
- **NextAuth.js v4**: Secure session management with JWT
- **User Dropdown**: Avatar, account menu, membership, sign-out
- **Sign-In Dialog**: Modal with provider selection

### 9. MCP (Model Context Protocol) Manifest

- **Endpoint**: `GET /api/mcp/manifest` returns JSON manifest
- **AI Agent Integration**: Enables external AI agents to discover and use platform capabilities

## API Endpoints

| Endpoint          | Method | Description                                      |
| ----------------- | ------ | ------------------------------------------------ |
| `/api/prices`     | GET    | Coin prices + global market data from CoinGecko   |
| `/api/news`       | GET    | AI news aggregation with sentiment classification |
| `/api/fear-greed` | GET    | Fear & Greed Index data                          |
| `/api/ai/digest`  | GET    | AI-generated market digest                       |
| `/api/ai/chat`    | POST   | Conversational AI chat endpoint                  |
| `/api/mcp/manifest` | GET  | MCP manifest for AI agent discovery              |
| `/api/auth/[...nextauth]` | * | NextAuth.js authentication routes       |
| `/api/auth/wallet` | POST  | Wallet address authentication                    |
| `/api/admin/users` | GET   | Admin user management                            |

### Query Parameters

**`/api/news`**
- `q` — Search query (default: "cryptocurrency AI blockchain")
- `num` — Number of results 1-50 (default: 20)
- `recency_days` — Recency filter 1-30 (default: 7)
- `locale` — Language: "en" or "zh" (default: "en")

**`/api/ai/chat`** (POST body)
- `message` — User message (required)
- `history` — Array of `{role, content}` for multi-turn context
- `locale` — "en" or "zh" for response language

## Deployment Guide

### Prerequisites

- **Node.js** >= 18
- **Bun** >= 1.0 (recommended package manager)
- **SQLite** (bundled with Prisma)

### Environment Variables

Create a `.env` file in the project root:

```env
# Required for AI features
ANTHROPIC_API_KEY=your-anthropic-api-key

# Required for authentication
NEXTAUTH_SECRET=your-nextauth-secret
NEXTAUTH_URL=http://localhost:3000

# OAuth providers (optional)
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret
TWITTER_CLIENT_ID=your-twitter-client-id
TWITTER_CLIENT_SECRET=your-twitter-client-secret

# Database (defaults to SQLite)
DATABASE_URL=file:./db/custom.db
```

### Quick Start (Development)

```bash
# Install dependencies
bun install

# Initialize database
bun run db:push

# Start development server
bun run dev
```

The application will be available at `http://localhost:3000`.

### Production Deployment

#### Option 1: Standalone Build

```bash
# Build the application
bun run build

# Start production server
bun run start
```

#### Option 2: Docker Deployment

Create a `Dockerfile`:

```dockerfile
FROM oven/bun:1 AS base
WORKDIR /app

# Install dependencies
COPY package.json bun.lock ./
RUN bun install --frozen-lockfile

# Copy source
COPY . .

# Initialize database
RUN bun run db:push

# Build
RUN bun run build

# Expose port
EXPOSE 3000

# Start
CMD ["bun", "run", "start"]
```

```bash
# Build and run
docker build -t driftcrypto .
docker run -p 3000:3000 --env-file .env driftcrypto
```

#### Option 3: Vercel Deployment

1. Push code to GitHub
2. Connect repository in Vercel dashboard
3. Configure environment variables
4. Deploy — Vercel auto-detects Next.js

bun run db:reset

## Key Design Decisions

1. **Hydration-Safe i18n**: Uses `useSyncExternalStore` with a server snapshot returning 'en' to prevent React hydration mismatches. Client-side locale is synced from localStorage after mount.

2. **News Bilingual Fallback**: The news API accepts a `locale` parameter. When ZAI SDK is unavailable, Chinese mock data is returned for `locale=zh` and English mock data for `locale=en`. Real search results are language-agnostic.

3. **Sentiment Analysis**: Keyword-based classification with both English and Chinese keywords for comprehensive coverage.

4. **CSS Architecture**: Custom CSS variables for theme colors (gold, bullish, bearish, neutral) with dark mode as default. Tailwind CSS 4 with shadcn/ui components.

5. **Performance**: TanStack Query for server state with configurable stale times, automatic background refetching, and request deduplication.

## Troubleshooting

| Issue | Solution |
| ----- | -------- |
| Hydration mismatch | Already fixed via `useSyncExternalStore` + `suppressHydrationWarning` |
| CoinGecko 429 errors | Falls back to cached database data automatically |
| News API returns mock data | ZAI SDK initialization failed; check API key |
| AI Chat not responding | Verify `ANTHROPIC_API_KEY` in `.env` |
| Language not persisting | Check localStorage for `driftcrypto-locale` key |
| Database errors | Run `bun run db:push` to sync schema |
